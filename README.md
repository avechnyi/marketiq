# MarketIQ — сайт обучения и команды

Статический адаптивный сайт без сборщика и внешних библиотек. Включает главную страницу, контакты, политику конфиденциальности, FAQ, учебный симулятор условного спреда и мини-викторину.

## Файлы
- `index.html` — главная страница.
- `privacy.html` — информация о конфиденциальности и обработке данных.
- `script.js` — переходы в Telegram, симулятор и викторина.
- `assets/` — изображения сайта. Не удаляйте папку и не перемещайте изображения отдельно.
